# Changelog

## 0.2.0
- Добавлены шаги-файлы: загрузка файла на сервер MeshCentral (через админ-панель, по частям) или
  доставка по прямой ссылке (URL), указание пути назначения на устройстве, запуск после копирования
  с аргументами, проверка контрольной суммы, условие «не копировать повторно, если файл уже есть».
- Добавлена опция «Выполнить как вошедший пользователь» (для скриптов PowerShell и для запуска
  файла после установки) — автоматическая обёртка через модуль RunAsUser вместо SYSTEM-контекста.
- Раздел «Файлы» в админ-панели: список загруженных файлов, удаление.

## 0.1.0
- Первая версия: автозапуск последовательности скриптов на новых устройствах, повтор при ошибке (с задержкой), автовозобновление при переподключении устройства, страховка от «зависших» задач, дашборд с историей, ручной запуск на любом устройстве, вебхук по завершении/ошибке.
